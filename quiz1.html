設定 AI 引擎與 CORS 代理

解決瀏覽器跨域（CORS）阻擋與 API 連線問題

CORS 瀏覽器防跨域代理助手

開啟此功能將會透過公用安全代理伺服器轉發 API 請求，解決 OpenAI/DeepSeek 拒絕瀏覽器直接連線的問題。

隱私安全保證：

您的 API Key 將會儲存於您本機瀏覽器（localStorage）。如欲避免 CORS 困擾，強力推薦使用 **Google Gemini API**，它預設完美支援瀏覽器直接呼叫。

AI API 連線與安全診斷報告

檢測到連線異常，以下是為您分析的詳細原因與解決方案

系統錯誤報告 (Error Logs):

TypeError: Failed to fetch

提示：這通常意味著瀏覽器的安全防禦政策（CORS）阻擋了這次連線。

🛠️ 快速解決方案：

1

改用 Google Gemini API 最推薦 & 最穩定

Google Gemini 的伺服器**完全支援瀏覽器直接跨域連線**。如果你不想設定任何代理，只需在設定中換成 Gemini API Key 即可秒速生成。

2

開啟內建 CORS 代理，或安裝瀏覽器防跨域插件

請回到設定面板開啟「CORS 防跨域代理助手」；或在瀏覽器安裝 「Allow CORS: Access-Control-Allow-Origin」 擴充功能並將其啟用。
